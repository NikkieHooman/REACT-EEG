# Result-linked manuscript source

This template has NO empirical result macros or numeric tables until a complete
measured real cohort is collected. `fresh.report` writes all inputs in a separate
study/paper directory. Do not compile the template by filling missing values with
old accuracies. Missing authors, data-provenance review and venue-format review
remain visible in `submission_review.json` and `cohort_status.json`.

The template retains the READER topic and section order but replaces the old
provisional results with a fresh 420-run matched study. Old HGD, LOSO and specialist
tables are deliberately omitted: they are not produced by this new primary study.
Architecture definitions include the actual new initialization, positional-table
size, max-norm timing and exact pooling. This is a NEW refit, not a claim that the
new code generated historical tables. Existing test exposure is disclosed.

Read and revise the scientific discussion after inspecting all measured
comparisons. Automated finite-check success is not ethical/author approval or a
conference acceptance prediction. The package does not submit to any venue.
